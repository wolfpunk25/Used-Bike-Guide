Sharing images with the rest of the team

Images are saved in this browser only until you paste a GitHub token below. With one set, uploads are committed to the images branch and everyone working on the guide sees them — that is how several people in different places share one set of photos.

  1. Open github.com/settings/personal-access-tokens and click Generate new token.
  2. Generate a token with access to only the Used-Bike-Guide repository.
  3. Under Repository permissions set Contents: Read and write. Nothing else is needed.
  4. Paste it here.

The token is kept in this browser's local storage and sent only to github.com. Treat it like a password: do not set one on a shared or public machine, and revoke it on GitHub when you are done. Leave the box empty and save to turn sharing off.

This repository is public, so uploaded images are publicly visible. Do not upload anything that is not cleared for publication.
