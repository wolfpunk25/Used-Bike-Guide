# Watch list — new models not yet in the guide

These appeared in morebikes.co.uk coverage (first rides, long-termers, launches)
but are 2026/2027 models with no meaningful used market yet. A used guide should
not carry them until examples start appearing on the secondhand market — likely
the 2027 issues.

Re-check each quarter and promote when used stock appears.

| Model | Source | Notes |
|---|---|---|
| Suzuki GSX-8T | Long-termer | Retro-styled GSX-8S derivative |
| Suzuki SV-7GX | "hits dealers this summer" | Crossover on the new SV platform |
| Kawasaki Z650S | First Ride | Semi-faired Z650 |
| BMW F 450 GS | First Ride | New middleweight parallel twin |
| Triumph Trident 800 | First Ride | Larger Trident |
| AJS JFT 125 | Quick Spin | Learner-legal |
| Rieju Aventura 307 | New model | Small adventure |

Also worth tracking: Honda XL750 Transalp E-Clutch (E-Clutch variant of an entry
we already carry) and Triumph Speed Twin 1200 TFC (limited edition of an existing
entry) — both are variants rather than new entries, so they may only need a note
in the existing record.
